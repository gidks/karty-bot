# 🖤 Карты Не Врут — таро-бот для Telegram

Таро-бот с честным тоном: без мистического тумана, «как умная подруга». Три карты → живой разбор через нейросеть → разговор после расклада. Монетизация: 3 бесплатных расклада, дальше разовая оплата или подписка (ЮKassa + Telegram Stars).

## Быстрый старт
1. `cp .env.example .env` и заполни (токен бота, ключ нейросети, свой Telegram ID)
2. `pip install -r requirements.txt`
3. `python bot.py`

Подробно для не-программиста: **ЗАПУСК_ПОШАГОВО.md**. Стратегия запуска: **ПЛАН_ПРОДВИЖЕНИЯ.md**.

## Что умеет
- Онбординг с именем, меню на кнопках
- 4 типа расклада: классика (3 карты, по темам), «Да или нет» (1 карта, прямой ответ), «Выбор из двух» (вариант А / вариант Б / что учесть), «Что он чувствует» (его чувства / что скрыто / твой ход)
- Колода полная — 78 карт (с перевёрнутыми) → честный разбор → диалог (до 5 реплик; по подписке — без лимита)
- Серийная подача разбора: карта раскрывается за картой (отдельными сообщениями с паузами), под каждой — свёрнутая справка «что это за карта», в конце — итог и подсказки-реплики для продолжения разговора
- «Неделя»-сериал: расклад «Неделя вперёд» приходит целиком сразу, а потом каждое утро бот присылает кусочек текущего дня из этого же расклада
- Оценка расклада 👍/👎 (сводка в `/stats`) и «память»: бот учитывает прошлые расклады пользователя
- Напоминание через 2 дня тем, кто не потратил бесплатные расклады (один раз, не спам)
- Карта дня: по кнопке раз в день + утренняя рассылка в 9:00 МСК по подписке
- Пейволл после 3 бесплатных: 1 расклад / неделя / месяц
- Оплата: Telegram Stars (работает сразу) и ЮKassa (карта, для самозанятых), защита от двойного начисления
- Рефералка: +1 бесплатный расклад за подругу, сделавшую первый расклад
- Follow-up «как всё сложилось?» через 3 дня после расклада
- Метки источников трафика (`?start=src_имя`) и админка: `/stats`, `/broadcast`

## Файлы
| Файл | Что делает |
|---|---|
| `bot.py` | Точка входа |
| `config.py` / `.env` | Настройки |
| `handlers.py` | Вся логика диалогов и оплат |
| `cards.py` | Полная колода: 78 карт (22 старших + 56 младших) с честными описаниями |
| `prompts.py` | Персона и правила для нейросети |
| `texts.py` | Все тексты интерфейса |
| `keyboards.py` | Кнопки |
| `serial.py` | Парсер серийной подачи: блоки карт, итог, подсказки |
| `database.py` | SQLite: пользователи, расклады, платежи |
| `llm.py` | Клиент нейросети (любой OpenAI-совместимый API) |
| `payments.py` | ЮKassa |
| `scheduler.py` | Карта дня 9:00, «Неделя»-сериал и follow-up |

Смена провайдера нейросети = одна строка `LLM_BASE_URL` в `.env`, код не трогаем.

18+, развлекательный формат.
